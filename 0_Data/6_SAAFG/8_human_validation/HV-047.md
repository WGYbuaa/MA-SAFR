Requirement Description:
The AI assistant must seamlessly integrate external data sources via Model Context Protocol (MCP) tools, such as web scrapers, to dynamically enrich its operational context. Upon analyzing ingested content, the system should be empowered to automate local environment tasks, including shell command execution for configuration management and authentication asset retrieval, while implementing a user confirmation step for high-privilege actions to ensure oversight.

Functional Flow:
- BF1: The AI assistant integrates external data sources via Model Context Protocol (MCP) tools.
- BF2: The system analyzes the ingested content.
- BF3: The system evaluates the action privilege level.
- BF4: The system requests user confirmation for high-privilege actions.
- BF5: The system executes shell commands for configuration management.
- BF6: The system retrieves authentication assets.
